### Funcionalitats
El programa permet:
- Crear un telèfon amb una marca i un model.
- Fer una trucada a un número de telèfon.
- Fer una fotografia.
- Activar una alarma.
- Combinar herència i implementació d'interfícies en una mateixa classe.
