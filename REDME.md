# Tasca S1.01 - Herència i Polimorfisme

A collection of Java exercises exploring **inheritance** and **polymorphism**, organized by difficulty level. This project was built with Maven and Java 25.

Each exercise lives in its own folder and includes its own `README.md` with specific notes, reflections, and usage details.

## Project structure

```
src/main/java/org/example/
├── nivell1/
│   ├── exercici1/   # Instruments: initialization blocks vs static blocks
│   └── exercici2/   # Car: final, static and static final attributes
├── nivell2/
│   └── exercici1/   # Smartphone: inheritance + interfaces (Camera, Clock)
└── nivell3/
    └── exercici1/   # Console app to manage editors and news stories
```

## Exercises

| Level | Exercise | Topic | Details |

| 1 | [exercici1](src/main/java/org/example/nivell1/exercici1) | Instance initialization blocks vs. `static` blocks | [README](src/main/java/org/example/nivell1/exercici1/README.md) |
| 1 | [exercici2](src/main/java/org/example/nivell1/exercici2) | `final`, `static` and `static final` attributes in a `Car` class | [README](src/main/java/org/example/nivell1/exercici2/README.md) |
| 2 | [exercici1](src/main/java/org/example/nivell2/exercici1) | Combining inheritance and interfaces in a `Smartphone` class | [README](src/main/java/org/example/nivell2/exercici1/README.md) |
| 3 | [exercici1](src/main/java/org/example/nivell3/exercici1) | Console app to manage editors and news (add/remove, scoring, pricing) | [README](src/main/java/org/example/nivell3/exercici1/README.md) |
